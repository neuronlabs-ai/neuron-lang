The Problem It Solves

In quantitative trading and machine learning, lookahead bias and data leakage produce backtests with 95% simulated accuracy that instantly collapse in live production. Python, PyTest, Mypy, and IDEs are completely blind to these bugs because the syntax is valid.

4 Specialized Defense Layers

Layer 1

AST Data Provenance (F001, F002)

Does not just rely on variable names. Tracks partition lineage across pd.concat, aliases (X_eval = X_test), reassignments, and helper function return values.

Layer 2

Temporal Leaks (T001–T017)

Catches negative leads (shift(-1), diff(-5)), non-causal centered rolling windows, time-series random shuffle splits, and lookahead joins (merge_asof).

Layer 3

Target Laundering (T017)

Flags un-split global target aggregations (df.groupby()['target']) while validating fold-local transformations with .fillna() inference fallbacks.

Layer 4

Causal & Uncertainty (C001–U006)

Detects correlation used for causal decisions, target in feature matrix, survivorship bias filtering, and uncalibrated point predictions without uncertainty bounds.
